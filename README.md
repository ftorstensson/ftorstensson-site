# ftorstensson-site

The new ftorstensson.com.

- The repo root is what gets published (index.html at the root). Every push to `main` deploys it to GitHub Pages.
- Live: https://www.ftorstensson.com (custom domain via the `CNAME` file). Preview path https://ftorstensson.github.io/ftorstensson-site/ now redirects there.
- Search engines: allowed since launch (4 Nov 2026).
- Design owns the look (the design chat's prototype is the source of truth); the website chat builds and publishes. No visual changes here without design.
- The domain switch follows `site-pipeline-and-dns-plan.md` in the Design Lab project, only on Fred's go.
