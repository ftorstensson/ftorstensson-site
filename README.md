# ftorstensson-site

The new ftorstensson.com. **Preview only, not live.**

- `site/` is what gets published. Every push to `main` deploys it to GitHub Pages.
- Preview: https://ftorstensson.github.io/ftorstensson-site/
- Kept out of search engines until launch: `noindex` meta in every page and `robots.txt` with `Disallow: /`. Remove both in the launch commit.
- Design owns the look (the design chat's prototype is the source of truth); the website chat builds and publishes. No visual changes here without design.
- The domain switch follows `site-pipeline-and-dns-plan.md` in the Design Lab project, only on Fred's go.
